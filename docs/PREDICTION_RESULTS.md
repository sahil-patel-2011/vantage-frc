## Method

- Features: year auto/teleop/endgame ratings, optional OPR / CCWM / DPR, recent form, scout cycles, climb rate.
- Model: calibrated linear blend (`calibrated-linear-v2`) — per-robot rating, then **0.50 alliance interaction** so three robots are not summed as if they each score a full independent match, minus a small opponent defense term.
- Split (when a season is present): whatever is in the cache; this script does not re-ingest.
- A match with missing alliance metrics is skipped, never filled.
